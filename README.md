# Portfolio (React + Vite)

```bash
npm install
npm run dev      # local preview at http://localhost:5173
npm run build    # static site in dist/
```

- Edit content in `src/data.js` (projects, experience, skills, stats).
- Images and the resume PDF live in `public/`.
- `dist/` can be uploaded as-is to GitHub Pages, Netlify or Vercel (`base: './'` is set, so sub-paths work).
